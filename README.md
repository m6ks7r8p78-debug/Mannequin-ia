# Mannequin IA

Générateur de mannequins **fictifs** féminins et masculins, inspirés d'une photo sans jamais copier la personne.
Hébergé gratuitement sur Cloudflare Workers (Workers AI : Gemma 3 pour l'analyse, FLUX.1 schnell pour l'image).

Chaque image porte un marquage XMP « générée par IA » (AI Act, art. 50).
