# Entraînement IA vidéo (Kaggle, gratuit)

Carnet `entrainement_video.ipynb` : repère automatiquement les passages où la personne fume dans tes vidéos,
les découpe en clips de 3 s, puis entraîne un module LoRA pour l'IA vidéo libre Wan 2.1 (1.3B) et crée des vidéos test.

Réglages Kaggle : Accelerator `GPU T4 x2`, Internet activé, vidéos ajoutées avec « Add Input ».
Lancer avec « Save Version → Save & Run All (Commit) ». Résultats dans l'onglet Output.

Uniquement des vidéos libres de droits, avec des adultes consentants.
